# Dispatch Operator

Offline-first emergency dispatch strategy game built with vanilla JavaScript and Capacitor.

## Run locally

```sh
npm install
npm run setup-assets
npm run serve
```

Open the printed localhost URL. The service worker caches the app shell for later offline play. City grids, vehicle illustrations, interface effects, and fallback tones are generated locally; the included city graphs are fictional training layouts, not surveyed street data. No runtime network access or third-party media downloads are required.

## Vercel

Import the repository into Vercel with the repository root as the project root. [vercel.json](./vercel.json) runs the asset-generation build and serves the `www` directory, where the app entry point lives.

## Android

Requires JDK 17 and Android SDK Platform 36/build tools. The Android project and `android/app/src/main/AndroidManifest.xml` are generated by Capacitor:

```sh
npm install
npm run setup-assets
npx cap add android
npx cap sync android
cd android
./gradlew assembleRelease
```

The unsigned release APK is written to `android/app/build/outputs/apk/release/`. To produce a distributable signed APK or AAB, configure signing credentials in the Android Gradle build configuration and use `./gradlew bundleRelease`.

## Gameplay and local scenarios

Select an incoming call and dispatch an available unit. Ground vehicles route along the local intersection graph; aircraft use direct routes. Each unit is assigned a crew member. The clearly labeled Scenario Editor saves, tests, imports, and exports local training calls.

Browser speech synthesis is used when available; voice choice and quality depend on voices installed by the operating system. Sound effects are synthesized locally when optional audio files are absent.
